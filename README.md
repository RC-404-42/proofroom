# 校稿間

一個不需要後端的多版本文字比較工具，適合校對角色卡、寫作稿、公告、措辭與程式碼。
老樣子的 VIBE CODE 產品，感謝我的 GPT。

## 功能

- 同時比較 2、3 或 4 份稿件
- 逐行對比與跨行智慧相似比對
- 相同／相似片段高亮
- 每份稿件皆可即時編輯、複製與貼上
- 尋找、上一筆／下一筆、單筆取代、全部取代
- 可選擇目前稿件或全部稿件，支援區分大小寫
- 顯示字數、行數、與 A 稿相似度及整體一致度
- 自動保留在瀏覽器本機，重新整理不會遺失
- 響應式深色介面

## GitHub Pages

將這四個檔案放在 GitHub 儲存庫最外層，並在 Pages 設定中選擇從 `main` 分支的根目錄發佈即可。

也可以直接開啟 `index.html` 使用；剪貼簿的「貼上」按鈕在本機檔案模式可能受瀏覽器限制，此時可使用 `Ctrl + V`。

## 技術

純 HTML、CSS、JavaScript，無框架、無外部套件、無遠端服務。所有輸入文字只保存在目前瀏覽器的 `localStorage`。
